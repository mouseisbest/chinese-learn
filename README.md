# 认字练习

给孩子认汉字用的网页程序。出一个字，孩子点「认识」或「不认识」，
程序按艾宾浩斯遗忘曲线安排复习——认得的字间隔逐步拉长，
不认得的字第二天必看，没掌握的字最多隔 7 天也会再滚一遍。

数据存在本机 SQLite 文件里。孩子用平板或手机连同一个 WiFi，
打开浏览器就能用，不需要装任何东西。

## 快速开始

```bash
./run.sh start
```

会编译并后台启动，然后打印访问地址：

```
✓ 已启动（PID 1185906）

访问地址
  本机      http://localhost:8090
  平板/手机（需连同一个 WiFi）
  http://192.168.1.23:8090
```

在电脑上打开本机地址，在平板上打开局域网地址。

### run.sh 命令

| 命令 | 说明 |
|---|---|
| `./run.sh start` | 后台启动（默认）。源码有改动会自动重新编译 |
| `./run.sh stop` | 停止 |
| `./run.sh restart` | 重启 |
| `./run.sh status` | 查看运行状态、访问地址、字表规模 |
| `./run.sh log` | 跟踪日志 |
| `./run.sh fg` | 前台运行，Ctrl+C 退出（看启动报错用） |
| `./run.sh dev` | 开发模式：改模板刷新即见 |
| `./run.sh backup` | 备份数据库 |

### stop.sh 命令

| 命令 | 说明 |
|---|---|
| `./stop.sh` | 停止程序（同 `run.sh stop`，另外会提示未记录的残留进程） |
| `./stop.sh -a` | 停止所有 `chinese-learn` 进程，**包括孤儿进程** |
| `./stop.sh -f` | 强制停止（直接 `kill -9`，不等优雅关闭）。隐含 `-a` |

**什么时候需要 stop.sh**：程序被手工启动过（`./chinese-learn ...`）、
换过数据库路径启动、或者 PID 文件被误删——这些进程还占着端口，
但 `run.sh stop` 找不到它们。`stop.sh` 会按名字扫出所有进程并停掉。

```bash
./stop.sh          # 正常停止；如果发现有残留进程会提示
./stop.sh -a       # 一并停掉残留进程
```

### 环境变量

| 变量 | 默认值 | 说明 |
|---|---|---|
| `ADDR` | `0.0.0.0:8090` | 监听地址。只想本机访问就设成 `127.0.0.1:8090` |
| `DB` | `data/chinese.db` | 数据库文件路径 |

```bash
# 换端口
ADDR=0.0.0.0:9000 ./run.sh start

# 换个数据库（比如给第二个孩子单独一份）
DB=data/child2.db ./run.sh start
```

### 直接运行二进制

不想用脚本也可以：

```bash
go build -o chinese-learn .
./chinese-learn -addr 0.0.0.0:8090
```

| 参数 | 默认值 | 说明 |
|---|---|---|
| `-addr` | `0.0.0.0:8080` | 监听地址 |
| `-db` | `data/chinese.db` | 数据库文件路径 |
| `-dev` | `false` | 开发模式 |
| `-log` | `info` | 日志级别：debug / info / warn / error |

> 注意二进制本身的默认端口是 8080，脚本用的是 8090（脚本通过 `-addr` 传入）。

## 怎么用

### 1. 导入生字

打开「导入」页，把生字内容粘进文本框——**什么格式都行**：

- 一行一个字：`天 地 人`
- 一整篇课文
- 带拼音的字表
- 带序号、标点的任何文本

程序会自动找出里面所有汉字、去掉重复的、保持出现顺序。
标点、数字、拼音、英文字母会被自动忽略。

点「预览一下」会显示抽出了多少个字、前 20 个长什么样、有多少是已经学过的。
**确认无误后再点「确认导入」**——预览阶段不写数据库。

同一份内容重复导入是安全的，不会产生重复的字。

### 2. 让孩子复习

打开首页，点「开始」。屏幕上会出一个很大的字，下面两个大按钮：

- **认识**（绿色）
- **不认识**（橙色）

出字时会自动朗读一遍。点完立刻出下一个字，没有等待。

家长陪读时可以用键盘：`1` / `←` = 认识，`2` / `→` = 不认识，
`空格` = 再读一遍，`退格` = 撤销上一个。

### 3. 看进度

首页按学期显示进度。点「字表」能看到每个字的等级、
下次复习日期、累计对错次数。

## 复习是怎么安排的

每个字独立跟踪一个等级，等级决定下次复习的间隔：

```
认识 → 1 → 2 → 4 → 7 → 15 → 30 → 60 → 90 天，逐级拉长
不认识 → 退回重来，第二天必定再看一次
连续 3 次不认识 → 退回重新学
```

另外有两条硬性保证：

- **第 2 / 3 / 7 天固定复习**（从首次学习那天算起）
- **没掌握的字最多隔 7 天就会再滚一遍**，不管间隔拉到多长

等级到 7（间隔 30 天）才算「已掌握」，之后按 15/30/60/90 天的长间隔自然复习。
这条线定在 7 而不是更低，是因为小学生连着认对几次未必是真记住了。

### 学期

可以建多个学期（「一年级上册」「一年级下册」……）。

- **新字只从当前学期放出**——学期没切，不会突然冒出下学期的字
- **待复习跨所有学期**——上学期没学会的字照样天天出现

所以升学期时旧字不会丢。在「设置」页切换当前学期。

## 每天的量

默认每天最多引入 **5** 个新字、一次最多复习 **20** 个。
孩子做完一批可以点「再练一批」继续，也可以「今天到此为止」。

这两个值在「设置」页可以调。**字少设小一点，孩子更容易坚持。**

如果某天没学，积压的字不会一次性堆给孩子——
每次仍然只出 20 个，且优先补欠得最久的。

## 数据与备份

所有数据在 `data/chinese.db` 一个文件里。

> **注意**：程序使用 WAL 模式，直接复制 `.db` 文件可能拿到不完整的快照。
> 备份请用：
> ```bash
> sqlite3 data/chinese.db "VACUUM INTO 'backup-2026-09-16.db'"
> ```

`data/` 目录不要提交到版本库。

## 技术说明

- Go 标准库起 HTTP 服务，唯一的外部依赖是 SQLite 驱动
- 模板和静态资源用 `embed` 打进二进制，**部署就是拷一个文件**
- 前端是原生 HTML/CSS/JS，没有任何构建步骤
- 朗读用浏览器自带的语音合成，不可用时自动降级

### 代码结构

```
internal/
  day/        学习日换算（日切点、跨天判定）
  schedule/   调度算法——纯函数，可穷举测试
  hanzi/      从任意文本中抽取汉字
  store/      所有数据库访问
  web/        HTTP 接口与页面
```

`day` / `schedule` / `hanzi` 三个包是纯函数，不碰数据库、不碰全局状态。
调度逻辑能被完整测试，不会被数据库细节污染——这是刻意的分界线。

### 开发

```bash
go test ./...              # 跑全部测试
go run . -dev -addr :8080  # 开发模式，改模板刷新即见
```

## 已知限制

- 没有登录和权限控制（设计前提是家庭局域网使用）
- 繁体和简体被当作不同的字（不做自动转换）
- 自评模式意味着孩子可以乱点「认识」——家长可在字表页查看对错记录
